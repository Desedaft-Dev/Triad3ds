# Triad3ds
 A client for the TriadCity MUD. Works by using the telnet connection method. This client comes with a stats display and keybinds to make navigating and playing easier.
 
**AI Notice**

AI was used to develop some parts of this program. I am not brain-dead vibe coding, I do understand the code the AI is providing and checking it for bugs and errors. I am using AI in the first place as I am unfamiliar with the ways of 3ds homebrew development and good documentation is scarce.

**Keybinds**

Circlepad Up/Down: Scroll text feed
Dpad Up/Down/Left/Right: move north, east, south, west
X: Send previous command
Start: Disconnect from TriadCity.
